# Hibernate Framework

This repository contains my learning and practice work with the **Hibernate Framework** using Java. The project focuses on understanding ORM concepts and performing database operations using Hibernate.

## 🛠️ Technologies Used

* Java
* Hibernate
* JPA
* MySQL
* Maven
* Eclipse IDE

## 📚 Topics Covered

* Introduction to Hibernate
* ORM (Object Relational Mapping)
* Hibernate Configuration
* `hibernate.cfg.xml`
* SessionFactory and Session
* Transactions
* Entity Classes
* Hibernate Annotations
* CRUD Operations
* HQL (Hibernate Query Language)
* Primary Key and ID Generation
* Entity Relationships
* One-to-One Mapping
* One-to-Many Mapping
* Many-to-One Mapping
* Many-to-Many Mapping
* Lazy and Eager Loading

## 🎯 Purpose of the Project

The purpose of this project is to understand how Hibernate works as an ORM framework and how it helps Java applications interact with relational databases using Java objects.

I am using this repository to practice different Hibernate concepts and build a strong foundation in ORM and database integration.

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in Eclipse or any Java IDE.
3. Configure the database details in `hibernate.cfg.xml`.
4. Update the required dependencies in `pom.xml`.
5. Run the Java programs to practice Hibernate operations.
